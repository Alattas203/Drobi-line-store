# دروبي لاين — Drobi Line Store

متجر إلكتروني لـ **دروبي لاين للاتصالات** في جدة (شارع فلسطين، حي الشرفية): جوالات أصلية، إكسسوارات، وصيانة معتمدة — بضمان سنتين، توصيل بنفس اليوم، وتقسيط عبر تابي وتمارا.

## محتوى المستودع

| المجلد                       | الوصف                                                                                            |
| ---------------------------- | ------------------------------------------------------------------------------------------------ |
| `preview/index.html`         | الصفحة الرئيسية — افتحها في المتصفح مباشرة                                                       |
| `preview/css/global.css`     | ستايلات كل الصفحات: الألوان، الأزرار، الهيدر، الفوتر، السلة                                      |
| `preview/css/pages/home.css` | ستايلات الصفحة الرئيسية بنفس ترتيب أقسامها                                                       |
| `preview/js/global.js`       | سلوك كل الصفحات: السلة، القوائم، المنتجات                                                        |
| `preview/js/pages/home.js`   | سلوك الصفحة الرئيسية: الواجهة، الفلاتر، الحاسبة، الاستبدال، الفرع                                |
| `nextjs/`                    | مكوّن الهيدر بـ Next.js + TypeScript + Tailwind + shadcn/ui، مع شرح التركيب في `nextjs/SETUP.md` |

## أقسام الموقع

- هيدر: الشعار، بحث في النص، الحساب والمفضلة والسلة، وسطر أقسام بقوائم منسدلة عريضة
- واجهة رئيسية بعروض متغيرة
- منتجات بفلاتر (وصل حديثاً، آيفون، سامسونج، إكسسوارات، مستعمل مضمون، تخفيضات) ومفضلة
- اختيار لون الجهاز
- حاسبة صيانة وأداة استبدال مع حجز عبر الواتساب
- فرع الشرفية: حالة مفتوح/مغلق بتوقيت جدة وأوقات الدوام
- سلة جانبية تحسب الضريبة 15% والتوصيل وترسل الطلب على الواتساب

## التشغيل

```bash
# النموذج
open preview/index.html

# مكون Next.js — راجع nextjs/SETUP.md
```

> الأسعار والصور في النموذج تجريبية، وتُستبدل ببيانات المتجر الفعلية.
